# desktop pet 共创投稿

这里用于 **desktop pet 共创平台**的桌宠、插件投稿与审核。作品由投稿者自行制作；也可以提交保留原格式、许可和附属文件的现有项目。

[进入共创平台](https://desktoppet-e9e.pages.dev)

## 如何投稿

1. 在共创平台的制作或导入模块填写作品信息，导出完整 ZIP。
2. 在本仓库的 **Issues → New issue** 中选择“桌宠投稿”或“插件投稿”。
3. 填写表单，将完整 ZIP 拖入表单的附件栏，并可附上封面和动作演示。
4. 提交后等待维护者审核。提交 Issue 或 PR 表示已送审，**不表示作品已在广场公开或已验证兼容**。

如果已经自行制作，只需提交完整文件与作品信息，不必在网站重新制作。熟悉 Git 的作者也可以提交 PR，并附同样的作品信息与完整文件。

## 桌宠作品

- 动作名称与种类可以自定义；请说明实际动作素材与名称、状态绑定。
- 可以提交视频动作、动画 WebP、图集，或保留原项目格式的完整文件。
- 投稿与下载保留原件。兼容报告说明哪些功能可以在 desktop pet 中直接使用；不兼容功能不会被冒称可运行。
- 依赖其他原应用或运行环境的作品，请附环境、版本和导入说明。不会自动执行包内脚本，也不保证任意项目能直接独立运行。

## 插件作品

- 自行制作后上传完整插件 ZIP，填写名称、版本、说明和许可。
- 声明插件实际需要的权限、网络服务及外部依赖；有 `manifest.json` 时一并保留。
- 原生插件按本系统权限与 SDK 运行；其他平台的插件保留原项目格式，按原应用说明使用。

## 署名与许可

请在包内保留 `LICENSE`、版权声明、必要署名与素材说明，并填写实际允许的分发范围。代码许可、素材许可和角色或商标权利分别说明；不会把 MIT 代码许可自动解释成所有素材或角色均获授权。

本仓库的说明与投稿模板采用 MIT 许可。投稿作品继续适用其作者明确的许可与限制，不自动改为 MIT。

## 附件要求

提交能够完整保存和导入的作品文件，而不只是截图或封面。不要把 API 密钥、令牌、账号导出、私人聊天记录或个人配置放入公开附件。文件较大时按 GitHub 当前界面提示上传，或提供投稿者有权公开的固定下载地址。

本仓库不接收代购、充值或付费开通请求。
