# 本地桌宠制作界面

`PetCreator.tsx` 在现有宠物页内提供制作窗口，不拥有文件读取、安装或持久化状态。输入类型来自主进程纯契约 `pet-authoring-types.ts`；主进程返回文件名、选择凭证和受限预览，渲染器不接收源路径。

窗口依次选择已有 V2 图集、填写规范字段、查看共享 `SpriteFrame` 预览、明确创建。选择和提交使用局部忙碌状态，取消可在提交等待时请求；替换或卸载使迟到响应失效。成功交给原宠物页刷新并打开详情，安装结果不会因界面刷新失败被称为创建失败。

`pet-creator.css` 仅限定制作窗口的表单、预览和操作排列，保留控制中心主题。
