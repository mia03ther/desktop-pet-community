# 电脑守护

这是桌宠工作室的可选宿主工具插件，插件 ID 为 `lingyin.computer-care`。它不随桌面默认安装，也不会因下载而启用。

下载网站 ZIP，解压后在本地控制中心「插件管理」导入包含 `openpets.plugin.json` 的文件夹，确认权限并启用，再从该插件的本机配置进入工具。下载监测等选项由用户主动开启。

- 查看内存、磁盘及自启情况，获得释放资源和修改保存路径等建议。
- 提醒可能有捆绑风险的下载行为；提醒不是对安装包安全的保证。
- 只读检查选择的 EXE/MSI 安装包，不执行安装程序。
- 核对选择的卸载残留目录，不自动卸载程序或删除文件。

权限为 `files`（用户选择文件与目录）、`system:metrics`（资源读取）及 `status`（插件状态）。JavaScript 入口只通过 SDK 显示启用状态；诊断、权限检查、监测生命周期与配置界面由匹配版本的桌宠工作室宿主实现。它不是能在任意 OpenPets 宿主独立运行的系统优化程序，不申请网络、管理员命令或自动清理权限。
