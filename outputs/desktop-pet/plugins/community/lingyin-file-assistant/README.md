# 文件助手

这是桌宠工作室的可选宿主工具插件，插件 ID 为 `lingyin.file-assistant`。它不随桌面默认安装，也不会因下载而启用。

下载网站 ZIP，解压后在本地控制中心「插件管理」导入包含 `openpets.plugin.json` 的文件夹，确认权限并启用，再从该插件的本机配置进入工具。

- 快速询问文件位置并打开对应文件夹。
- 建立虚拟分类库，原件位置不因分类改变。
- 明确选择「按推荐整理」后执行计划，可按原记录撤销。
- 使用用户已经配置的 AI 提供方审核分类；不附带密钥或代配账号。

权限为 `files`（本机文件功能）与 `status`（插件状态）。JavaScript 入口只通过 SDK 显示启用状态；实际工具、权限检查与配置界面由匹配版本的桌宠工作室宿主实现。它不是能在任意 OpenPets 宿主独立运行的文件管理程序，也不自动整理或删除文件。

作者：桌宠工作室项目。插件清单与入口代码许可为 MIT；不包含用户文件、私人档案或第三方桌宠图集。
