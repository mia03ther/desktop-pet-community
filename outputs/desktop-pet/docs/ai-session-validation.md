# 真实会话验收

2026 年 10 月 10 日在 Windows 本机验收。范围按用户确认限定为已安装且已登录的平台；未安装宿主不代为安装，缺少登录或模型选择不冒称完成。对话 AI 与工作监测分开。

| 平台 | 实际证据 | 结论 |
| --- | --- | --- |
| DeepSeek Harness | 使用已有账户的官方临时 profile，真实模型调用写入并读回隔离文件；正式 Cordis 插件进入桌宠 IPC，9 条事件及实际窗口显示成功编辑 1 个文件。 | 模型、工具、事件和气泡通过。原有客户端需更新插件并重启才能加载新版。 |
| Claude Code | 使用已有 OAuth 登录与临时 Hooks 设置，真实模型完成 Write／Read；同会话工具事件、成功文件数和完成状态出现在真实桌宠窗口。 | 模型、工具、事件和气泡通过。原有客户端需更新托管 Hooks 并开始新会话。 |
| Codex | 已有 ChatGPT 登录，8 项自有 Hooks 均启用且受信。真实模型回合完成，但工具执行返回 `helper_unknown_error: setup refresh had errors`、退出码 -1，未产生本轮正式工作事件。 | 未通过完整验收；不能归因未信任或凭模型完成认定工具成功。 |
| ZCode | 本机桌面和 CLI 存在，终端提示 `Select a model before continuing`；官方只读查询未确认模型可用的登录。 | 未通过；需要在原客户端选择可用模型后重验。 |
| 豆包 PC／网页版 | PC 客户端存在；未取得并接通公开可用的客户端工作事件接口。方舟开发桥仅为独立应用提供事件调用。 | 客户端监测未实现，不能以安装、登录或开发桥自测替代。 |
| OpenCode、Pi、OpenClaw、Zed、Cursor | 未确认可用且登录的宿主。新增适配器行为测试与正式会话区分。 | 不在本轮真实会话验收范围。 |

验收使用实际 Electron 主进程、正式 IPC 和真实绘制气泡，测试窗口与用户窗口分开。临时 Codex 自有脚本和 ZCode 配置已经按备份逐字节恢复；Claude 使用临时设置，没有修改用户配置。用户正在工作的 AI 客户端没有被关闭或重启。

只读排查发现 Codex 沙箱刷新对官方运行时 `node_repl.exe` 检查执行权限时返回 Windows 错误 32（文件被其他进程占用），导致刷新失败；工作目录权限授予本身成功。日志证据与受信 Hooks 状态分开记录，不通过放宽沙箱绕过该问题。

原始本机记录不随源码公开。公开记录不包含账户、密钥、个人目录、真实聊天、命令内容、工具参数或文件原文。行为测试通过不等于尚未安装宿主的真实验收通过。
