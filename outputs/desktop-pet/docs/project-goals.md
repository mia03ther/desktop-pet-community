# 项目目标与当前范围

**当前交付状态：** 请先阅读[截至 2026-10-10 的交付与边界](release-status.md)。下文保留历史阶段范围；其中公网、测试数量和迁入资料保存等历史指标，以当前交付状态及对应最新验收为准。

本页以用户最新确认的目标为准。旧验收报告记录当时实现，不替代本页的当前范围。模块和阶段结构已获批准：生活与提醒 → 电脑与文件工具 → 多 AI → 共创。

## 桌宠与陪伴

- 自主溜达、休息、寻找活动，并对点击和拖拽作出不同反应；提供可选的喝水、久坐、休息和番茄钟提醒。
- 不抢窗口；可拖走、一键隐藏、全屏让位。用户要求去掉桌宠下方状态栏，默认保持关闭。
- 保留多来源 AI 配置、人物 skill 文本导入、对话和多 AI 分析协同。用户在应用内自行配置提供方。

## 电脑助手：已修改的四项目标

| 当前目标 | 当前进度 | 需要补齐的能力 |
| --- | --- | --- |
| 监测可能导致弹窗的行为，例如下载可能含捆绑的软件，并提醒 | 已交付用户选择下载目录后的可选浅层观察，以及新 EXE/MSI 的静态证据与复核提醒 | 没有覆盖全部下载行为或动态弹窗，新增文件不等于捆绑 |
| 安装前监测是否可能捆绑，并提醒 | 已交付原生选择一个 EXE/MSI，读取签名、SHA256、版本与来源标记，明确显示“捆绑待确认” | 静态证据不能全面检出安装时或后续联网取得的附加组件 |
| 监测并提醒卸载是否干净 | 已交付完整新鲜登记清单间的移除记录，并按用户操作核对此前保存的明确安装目录 | 只核对该目录，不猜测 AppData，不检测全盘、启动项或注册表残留，不判定全面清理 |
| 内存监测与优化建议，例如修改保存路径 | 已有 RAM、CPU、磁盘和进程采样；新增基于新鲜测量的资源建议 | 继续完善持续监测的解释与可操作建议；修改保存路径主要改善磁盘占用，不保证降低 RAM |

电脑助手以监测、提醒、证据和建议为当前目标。旧目标中自动关闭广告、自动卸载清理、自动删除残留和自动修改系统配置不再作为当前交付要求。用户拒绝提醒或暂缓提醒的设置继续保留。

上述三项软件能力现在位于工作室的 **电脑与文件 → 软件提醒**。本轮已完成实际窗口、只读文件采集、下载处置和目录核对验收，并重新生成本地无签名 Windows 便携包、验证原档案启动。相关测试通过；全量检查仍受旧测试的 Windows 符号链接权限限制。窗口验收替代了原生选择返回、时钟和软件登记输入，没有实际安装或卸载用户软件。

下载观察默认关闭，用户原生选择具体目录后再启用。每 30 秒只观察第一层，最多读取 200 个顶层条目；新增候选须至少两次有效观察、相隔不少于 10 秒且文件属性稳定才检查，稳定不保证下载已完成。首次、重启或重新启用先建立现有文件基线，不补报未观察期间的变化。支持忽略、延后 1 小时及恢复；隐藏桌宠时延后未送达提醒，不把桌宠唤出。

安装包检查不运行安装文件、不上传文件或调用远程信誉库；Windows 的 Authenticode 证书链验证可能按本机策略查询系统证书服务，因此不能承诺绝对离线。签名有效、未签名、关键词和来源标记均不直接证明有无捆绑。卸载目录存在可能是用户资料、共享组件或其他版本；未见该目录也不能证明全盘干净。详细使用与边界见 [电脑与文件助手](companion-tools.md)。

## 文件与 AI 工具

文件目标已改为两项：向桌宠询问文件在哪并打开所在文件夹；建立不改变原位置的智能分类库。收藏箱与跨设备传输已取消，不再列为缺口。

已有用户选择目录后的持久名称索引、六类本地规则与原因、分类／目录筛选，以及无需 AI 的本地文件询问。唯一明确匹配会在复验后请求 Windows 定位；多匹配列出候选。分类库只保存引用和元数据；AI 进一步优化先展示有界文件名／类型摘要，用户选定来源生成草稿，再明确采用，仍不移动文件。可选的“按推荐整理”另行展示逐项移动计划，确认后执行，冲突不覆盖并支持有条件撤销。具体操作、扫描上限及失效引用见 [文件分类库](companion-files.md)。

已有多个 AI 来源的配置、对话、实际调用状态、token 记录和限定提供方的余额读取；没有余额接口的来源允许手填，不能宣称通用实时额度监控。多 AI 电脑分析仅在用户确认数据预览后发送，不执行模型返回的系统命令。真实用户远程账号的连通性需要用户完成配置后验证。

工作监测覆盖本应用真实回合、协同任务和已接入的代理事件，不自动监测未接入的外部 AI。额度自动读取目前限于官方 DeepSeek 账户及 OpenRouter 密钥接口，其他来源使用手动记录或接口可用性说明。用户主动导入人物 Markdown 或完整 Skill 后自动启用，后续对话无需触发词；手动保存人设草稿默认停用。该接入提供人物文本参考，不执行任意 Skill 工具或脚本。

## 共创与项目传播

共创已迁到独立浏览器网站：支持桌宠 V1/V2 图集检查、动作预览、署名与兼容 ZIP 制作，以及声明式提醒插件制作和 ZIP 下载。控制中心只管理已安装内容、手动导入和本机配置，并保留网站入口。插件可直接导入 ZIP 或文件夹，先查看兼容性报告，原生兼容包沿既有权限确认与安装流程运行；托管的完整原项目副本持久保留原始清单、附属文件、署名说明及许可。当前网站随桌面包在本机运行，尚无成功公网部署；公共投稿、账号、审核与社区发布未开放。当前操作与托管状态见 [共创网站](community-website.md)，迁移前验收保留为历史记录。

继续研究高星开源项目，优先复用现有所有者和格式契约，记录具体阅读范围、来源和许可。吸引关注的工作重点是易运行的交付、真实演示、清晰的功能进度、可复现验收和方便贡献的说明。公开名称、独立仓库及发布方案需形成可审阅结果后再请用户批准。
