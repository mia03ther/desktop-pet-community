# 宠物大脑

在控制中心打开“宠物大脑”，查看同一桌宠对话与额度。“接入 AI”页可以保存多个提供方，也可以为同一提供方保存不同模型。每个配置都有独立名称、模型 ID、地址及凭据引用。全局 Markdown 与文本蒸馏在单独的“人设个性”页面。

## 自行配置来源

来源模板包含 OpenAI、Anthropic、DeepSeek、OpenRouter、Ollama、LM Studio、vLLM、MiniMax 与自定义兼容接口。模板不是已配置账号，模型 ID 应以用户提供方实际开放的模型为准。兼容接口使用 OpenAI Chat Completions 结构；Anthropic 使用原生 Messages 结构。并非所有声称兼容的网关都支持相同能力，请使用设置中的连接测试确认。

凭据在应用设置中填写，由原有凭据存储处理，不需要粘贴到聊天。桌宠生活、提醒及已安装启用的电脑守护、文件助手插件无需云端凭据。没有保存配置时，宠物大脑显示空状态，不代表已连接某个账号。

已知官方云端地址要求凭据，缺少时显示未就绪；兼容协议本身不代表免认证。本机或自定义网关是否需要凭据，按该接口实际认证设置填写。设置提示和请求就绪判定共用同一凭据规则。

对话使用当前选中的文字来源，保留同一桌宠的历史、能力校验、取消及语音互斥。发送入口只在桌宠旁的输入框，控制中心对话只展示内容。提醒与协同回复通过 publishDesktopMessage 写入既有会话历史与投影，按通知编号去重，不启动模型或改变活动回合；重启后的历史进入下一轮有界上下文。修改来源在下一回合生效，正在进行的回合保持已捕获配置。

## 本地问文件与 AI 分类

先从网站插件画廊下载“文件助手”（`lingyin.file-assistant`），在“插件管理”导入、启用并打开插件工具，添加资料目录，再输入“复习提纲在哪”“帮我找一下报告.pdf”。这些受支持的句式先查询本机索引，不需要配置 AI：唯一明确匹配复验后定位，多匹配返回候选。插件未安装或停用时只提示安装启用，不读取索引，也不打开文件夹；等待路径期间停用会阻止迟到结果打开目录。普通聊天继续使用当前 AI 来源；原对话历史与取消机制沿用。索引只覆盖添加的目录，新增或改变的文件需刷新。此类回合会保存文件名及回答到同一对话历史，之后普通 AI 聊天可能携带历史；本地定位本身不发起模型请求。

分类优化入口在文件助手中，复用用户自配的多个来源。先预览最多 200 条匿名编号、名字、类型和当前分类，选择就绪来源生成，再审阅采用；不上传正文或绝对路径。生成只返回临时草稿，采用只改库元数据，实际移动另走“按推荐整理”的具体计划。分类请求与实际响应 token 已接入监测；详情见 [文件分类库](companion-files.md)。

## 电脑问题与多个 AI 协作

先安装启用“电脑守护”（`lingyin.computer-care`），在“插件管理”的插件工具中点击“开始检查”，再展开该插件的“让多个 AI 协同分析”，输入问题并预览发送资料。预览、派发及刷新 AI 来源后的执行都重新校验插件权限和运行状态。停用插件取消从该控制中心派出的分析任务，并撤销未消费的预览；再次启用必须重新预览。预览包含采样时间、采样时长、CPU、内存、磁盘数值和采集问题数量；不包含窗口标题、进程名称、文件路径、自启命令或软件清单。用户自己输入的问题会随资料发送，请在预览时检查内容。

选择 1 到 3 个文字来源，指定其中一个汇总来源，再开始分析。单来源执行一次分析；多来源分别分析，再由指定来源综合一致结论、分歧和待确认项，最多四次模型请求。每次请求可能消耗提供方额度。部分来源失败会明确显示，指定汇总来源失败时不会自动换用另一个来源。问题、各来源回复与最终汇总均进入同一桌宠对话，不再展示独立分析记录。

分析任务没有工具执行权限；模型返回工具请求也不会执行。分析建议不等于实际修复，当前不会自动删除文件、结束进程、关闭广告或卸载软件。一个诊断采样不能确认广告来源或卡顿根因。实际文件整理仍需通过文件助手的具体计划执行。

任务支持取消和两分钟总时限，模型传输沿用原来的三十秒请求时限。关闭发起任务的控制中心会取消从该窗口发起的工作；不会取消其他宠物窗口拥有的对话。最近十条任务结果保存在本地档案，结果可能包含用户输入及模型回复，请勿公开上传档案目录。

## 额度情况

工作状态来自本桌宠的活动对话、分析任务、人设提炼任务和已接入的本地会话事件。来源配置就绪不等于 AI 正在工作。租约心跳只证明桥接会话还连接，终端标签不证明它属于哪个 AI。事件超过九十秒会标成待确认，租约结束显示断开；未连接的外部 AI 不在当前监测范围。

“对话 AI 额度”只显示桌宠对话来源；“外部 AI 监测”显示各真实外部会话、具体工具与成功编辑文件计数。外部会话及其账户额度不使用桌宠对话来源的 token 记录。

对话来源额度有三类信息，分别显示：

- 官方查询：用户主动点击查询，DeepSeek 官方来源读取账户余额；OpenRouter 官方来源读取单个 key 剩余支出上限。仅接受对应官方 HTTPS 地址，兼容网关不套用这些语义。查询记录五分钟后标为旧数据，配置变更后失效。
- 手动记录：按配置独立保存已用和剩余，可填百分比、请求数、token 或币种；旧记录缺少已用时保留未知；二十四小时或重置时间后标为过期。它不是实时账户查询。
- 实际用量：只显示提供方响应返回的完整 input/output token 计数，按配置聚合当前会话的有界记录与任务历史。计数通知沿用开始时固定的提供方配置；不包含未接入账户的其他软件消耗。缺失字段显示未知，不补成零，不推算余额。Anthropic 的 `input_tokens` 原值不包含独立缓存计数，当前不统计缓存总输入。

DeepSeek 的额度结构见[官方余额文档](https://api-docs.deepseek.com/api/get-user-balance/)；OpenRouter 的 `limit_remaining` 是 key 的支出上限余额，`null` 表示未设置该上限，不能称为账户余额无限，见[官方额度文档](https://openrouter.ai/docs/api_reference/limits)。OpenAI、Anthropic 等对话 API 来源当前没有接入账户余额查询，界面明确显示未支持。

外部 Codex 另有官方 App Server 只读订阅额度监测，默认关闭，用户启用后每两分钟查询当前配置的 CLI 已登录账户。固定协议不请求登录、认证刷新或生成任务；任何认证交互、未登录、API key 来源、版本错误、超时或缺失窗口都显示未知。多限制及主／次窗口分别显示已用、剩余、官方恢复时间；未知数值不补零。只保留额度投影和 CLI 版本，不返回账号身份，五分钟后的记录标过期。Hooks 未携带账户身份，故当前 CLI 窗口不能自动归给每一个会话。关闭监测、换 CLI 或退出会取消旧查询并清理自有进程。ZCode 等未提供已接入官方额度协议的外部来源仍未知。协议与操作边界见[外部接入](agent-integrations.md)。

当前界面不展示本桌宠累计消耗、手动已用或手动剩余三个统计区块，手动记录仅保留折叠配置入口。自动查询入口只为受支持的官方来源显示，并要求配置与凭据就绪。`provider-contract.ts` 的官方额度判定同时供实际请求与只读监测使用；监测只公开支持枚举，不公开来源地址或凭据引用。

## 人物资料

控制中心有独立的“人设个性”页面（`persona`），顶部“导入已蒸馏 Skill”支持 SKILL.md、Markdown 与 UTF-8 纯文本。全局 Markdown 方式支持自行编写、编辑、导入；蒸馏方式支持粘贴已有结果，或选择任一已配置且就绪的文字来源，从用户提供的资料提炼草稿。草稿不会自动保存或启用，用户审阅编辑后保存默认停用，再明确启用。

已启用人设适用于本桌宠的文字对话及协同分析的各个来源和汇总请求，不改变未接入的外部 AI 应用。文档不执行脚本、不展开相对引用，也不增加工具权限。这里的蒸馏是人物风格文本提炼，不训练模型权重。人设存档已升级 v2，兼容读取旧 v1；正文仅独立授权编辑 API 返回，普通监测快照无正文。提炼过程已接入来源工作状态和提供方实际 token 用量。详情见[人设个性与文本提炼](companion-persona.md)。

## 模块所有权与验证

`external-ai-activity.ts` 的有界会话投影由 `local-ipc.ts` 持有，真实 Hooks 最小元数据在原请求所有者校验后进入投影；`external-ai-progress.ts` 是界面与宠物浮层共用的纯文字格式。`codex-quota-client.ts` 拥有固定只读协议和短命 App Server 进程，复用外部命令所有者清理自有进程树；`codex-quota-monitor.ts` 拥有单一轮询、取消与短期缓存，启用偏好和 CLI 路径仍由原 `app-state`／`agent-setup` 保存。它们不访问桌宠对话提供方凭据。

本机 Codex CLI 0.162.0-alpha.2 的实际只读握手与额度查询已经返回官方窗口；这证明该 CLI 的查询路径可用，不代表 ZCode 等其他来源提供相同接口，或每个 Hooks 会话属于当前 CLI 账户。安全投影验证记录不包含账号身份。最终窗口布局与 Hooks 更新加载需随桌面版本集成验证。

`provider-service.ts` 与 `text-model-client.ts` 继续拥有凭据解析、固定操作快照、HTTP 生命周期和适配器编解码；按配置 ID 的操作不会修改当前选中来源。`companion-ai-tasks.ts` 拥有只读分析任务与有界历史；`companion-ai-monitor.ts` 只聚合最小证据并保存手动额度；`companion-persona.ts` 保存一份人物文档；`persona-distillation.ts` 持有不存档的生成状态与用量。`companion-ai-host.ts` 做协作者编排，`control-center-ai-ipc.ts` 校验发送方和预览归属、处理窗口关闭与退出清理。

测试使用隔离档案、固定模型响应和本机 HTTP 接口，覆盖配置固定、协议、用量、取消、只读边界与协同结果。此类测试证明程序接口工作，不代表已经连接用户的真实远程账号。用户提供方的实际连通与额度需要在设置中配置后查询确认。
