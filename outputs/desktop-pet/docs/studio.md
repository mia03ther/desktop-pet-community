# desktop pet 控制中心

本地控制中心独立管理桌宠、宠物大脑、人设和已安装插件。浏览、下载与共创位于独立网站。系统沿用原档案和既有插件权限、会话、图集与本机协议；界面不展示内部协议名或包标识。代码和素材署名仍保留在许可证、原包声明及相应元数据中。

日常双击桌面“desktop pet”显示桌宠，双击“desktop pet 控制中心”进入配置。快捷方式直接启动程序，重复点击复用正在运行的实例；旧启动脚本作为后备入口。桌宠右键菜单只有打开控制中心、动作、隐藏、对话和大小；连续两次右键与选择“对话”打开同一个输入框。隐藏后的恢复入口保留在托盘、快捷方式和用户配置的快捷键。

| 页面 | 操作 |
| --- | --- |
| 我的桌宠 | 动作预览、安静模式、自定义动作与 AI 状态映射；切换、显示、导入和移除 |
| 共创网站 | 网站桌宠、插件和制作入口 |
| 宠物大脑 | 接入多个 AI、外部 AI 事件桥接、查看统一对话与额度 |
| 人设个性 | 全局 Markdown、导入已蒸馏 Skill、AI 辅助提炼、保存及启用 |
| 插件管理 | 已安装插件的权限、启停、配置、命令和导入；插件画廊位于网站 |
| 设置 | 陪伴开关、大小、隐藏快捷键和开机启动 |

“我的桌宠”与侧栏陪伴席不提供隐藏和前往共创按钮；设置页不展示“来源与适配”。安装素材的署名及协议字段不在这些操作区域呈现，也不把第三方素材声明为本项目原创。

## 界面与布局

保留用户选定的 D 款头像图标。产品可见名称为 desktop pet。深灰顶栏、浅灰工作区、白灰卡片、金色边线和青色轻提示沿用现有设计；六页面仍分为陪伴与创作、助手与工具、工作室三组。

工作区按容器宽度调整卡片、表单和按钮；外部接入的详细命令和配置通过复制操作提供，技术协议不改名。焦点、滚动、减少动态效果及窗口最小宽度继续受实际界面验收约束。

## 导入兼容性与原项目

“我的桌宠”和“插件管理”通过“检测 ZIP 或文件夹”先读取静态兼容性报告，展示格式、原使用环境、本机可用能力与限制；确认后才导入。本系统兼容包继续使用原有安装、权限确认及运行逻辑，完整项目副本另外保存。

其他宿主项目完整保留，在“已保留的完整项目”中管理。当前系统无法提供的桌宠显示、动作管理、AI 联动或插件配置按钮为灰色，并在报告中说明原因；不兼容插件不会启用为本系统 SDK 插件。

桌宠和插件都提供“独立运行”。有可用的原项目程序时，由主进程在用户点击后启动该入口；入口不明确时可选择项目程序。缺少原运行环境时，可选择已安装的原应用，再从这里启动。只打开外部原应用时明确提示用户在该应用导入或打开保存目录，不将应用启动记为作品已运行。能力不可用时按钮为灰色，显示缺少环境或入口的原因。导入自身不启动项目；来源说明不在本地产品操作区显示，原包及许可证继续保留。

Shimeji 的“另建素材转换副本”是可选制作操作，需再次确认，只把无条件 PNG 姿势转换为本机素材，不改变原件，不把 Java、条件动作或原行为引擎标记为兼容。移除保存副本不删除原文件，也不移除已经安装的本机桌宠或插件。

## 桌宠动作

没有 AI 实际工作状态时，新旧档案均默认安静待机。单击随机播放已选候选动作，六秒后返回待机；关闭安静模式后，空闲时每四十五秒随机播放一次。真实工作事件优先，不凭保存了一个 API 来源就断言 AI 正在工作。

“自定义动作与 AI 联动”支持命名、新增、移除最多二十四个动作类型，每项绑定当前图集已有动画并设置是否参与随机。没有候选时待机。AI 反应映射引用真实图集动画，切换素材后使用其 V1/V2 布局。名字和映射先编辑再保存；安静开关仅即时保存已存配置。本次不包含新增动画素材制作。

## 宠物大脑和统一对话

“宠物大脑 → 接入 AI”配置桌宠实际使用的文字模型。可保存多个提供方、兼容接口及本机网关，再选择当前文字来源。正在进行的回合使用开始时捕获的配置；切换对后续回合生效。

与桌宠聊天只从桌宠旁的输入框发送。“宠物大脑 → 对话”仅展示同一会话，没有另一个编辑框或发送入口。桌宠提醒和协同分析也写入该历史，重启恢复后可见，并进入后续模型回合的有界上下文；插入提醒自身不调用 AI，不打断正在进行的回合。相同通知编号去重，历史仍受两百项、三十天与容量限制。

每条对话显示记录时间；旧数据没有时间时明确显示“时间未记录”。喝水、休息等实际显示的文字和 Markdown 提醒写入同一历史，保留发生时间，尚在气泡队列中等待的提醒不提前记入。桌宠提醒、回答与控制中心历史共用对话外观设置的字体、颜色、边框和圆角；停用自定义时共用默认外观。

协同任务的预览、AI 选择与派发在已启用的电脑守护插件配置中。模型仅接收用户预览确认的数值摘要；各模型回复和汇总进入同一对话，不另开分析结果工作区。关闭窗口或停用插件沿用原任务取消边界。

“额度情况”按已配置 AI 展示官方查询结果。DeepSeek 官方余额与 OpenRouter key 支出上限通过现有凭据服务主动查询；其他提供方没有通用余额接口时显示未提供。不再展示本桌宠记录的消耗、手动已用和手动剩余三个统计区块；折叠的手动配置入口与已有数据保留。实际响应的 token 计数仍用于内部记录，不等同全账户支出。外部活动桥接没有账户额度时不臆造数字。

自动查询按钮只在当前来源满足已支持官方地址与兼容文本协议时显示，缺少凭据或配置未就绪时禁用。该能力由主进程投影，不靠来源名称或模型名称猜测；界面能力与实际查询使用同一纯契约。

外部 AI 接入分别显示命令行程序检测、连接配置和近期真实事件。版本命令通过只说明程序能启动；配置文件存在不代替程序检测，检测超时也不等于未安装。当前匿名活动通道没有可可靠归属四种外部工具的真实会话记录，因此显示会话待确认；本机链路自测不会升级为真实会话已连接。豆包仍是用户自建方舟应用的本机开发接口，不检测网页或 PC 客户端。

## 导入已经蒸馏好的 Skill

入口为“人设个性 → 导入完整 Skill 文件夹”。保留 SKILL.md、manifest.json、references/ 和其他包内文件；也可打开技能目录，手动放入完整技能文件夹后扫描并选择。导入成功即选中并启用，每次文字对话与协同请求自动使用，不需要触发词。原有单文件 Markdown 导入与正文编辑继续保留。

导入是受限人设文本接入，读取 SKILL.md 和其在包内引用的文本，不执行脚本或 Skill 工具声明；正文和最终提示词有容量、UTF-8 与本机路径校验。环境检测分别说明宿主支持、当前文字 AI 就绪情况与尚未检测的外部平台能力，不把目录结构合格等同模型已遵从。AI 提炼只生成待审阅草稿，不训练权重，不自动保存或启用。详见[人设个性与文本提炼](companion-persona.md)。

## 插件与文件工具

本地只管理已经安装的插件，作品浏览、下载与共创在网站进行。文件助手与电脑守护继续为可选插件，启用与权限确认后才提供文件库、采样、提醒和协同配置。工具插件卸载后保留资料库、整理记录与电脑设置；重装可继续使用。

网站二十四个插件使用各自独立封面，卡片、详情和排行榜复用同一映射。生成 PNG 原件保存在 `outputs/plugin-covers-20261009/originals`，网站使用保持比例、无裁切的 960 像素宽 WebP；压缩字节数及摘要见同目录 `manifest.json`。本机预览仅登记这二十四个明确 WebP 路径，不开放封面目录的任意文件读取。

文件库保存对原文件的引用，默认不移动文件。问“报告.pdf 在哪”从同一桌宠输入框进行，唯一匹配复验后定位；AI 分类先预览名字和类型，生成后审阅采用；实际移动另走“按推荐整理”的具体计划确认。详见[文件分类库](companion-files.md)。

## 验证边界

主进程与 renderer 类型检查、对话通知归档和下一回合上下文、重启去重、运行中通知、协同消息出口、真实响应计数、旧额度记录以及文本 Skill 导入均由隔离测试验证。界面验收使用真实 Electron 窗口及隔离档案，检查窄窗口布局和输入入口；运行结果以本轮日志及截图为准。

本机模型替身和固定响应不代表已经连接用户的真实远程账号；用户来源的连通与额度应在配置后主动查询确认。

`smoke-community-native-packages.mjs` 使用专用验收目录中的全新档案，检查网页制作 ZIP 经桌面真实安装后，由隐藏 Electron 插件宿主实际注册并执行最小 SDK 3 命令；独立视频包使用既有十秒素材，读取自定义名称、种类与状态绑定，并由隐藏视频窗口实际解码播放。该脚本不访问网络、不使用用户档案、不把同一片段的状态引用计为新增动作；具体是否通过以本轮 `result.json` 为准。

2026-10-09 的 v12 r1 快照已通过这项真实闭环：插件收到 SDK 命令回执，视频保留自定义名称、分类及三项状态绑定，Chromium 实际播放 10.08 秒素材并解码十五帧。记录位于 `outputs/validation/community-native-packages/20261009-1654-r1/result/result.json`。脚本可通过 `DESKTOP_PET_SMOKE_SNAPSHOT` 选择 `dist` 内构建快照，或用 `DESKTOP_PET_SMOKE_TEST_BUILD=1` 选择已编译测试模块；不触发打包或个人版启动。
