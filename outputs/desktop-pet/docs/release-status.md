## AI 接入与额度的真实范围

- **Codex 额度已有真实成功证据。** 官方 CLI 的只读 App Server 返回过当前登录账户的额度窗口与恢复时间。可选监测默认关闭，开启后有界轮询，不执行登录、凭据刷新或生成任务；账户窗口由多个会话共享，不是逐会话费用。历史成功响应不当作此刻仍然新鲜的余额。
- **DeepSeek 对话及官方余额已有真实成功证据。** 已通过已配置提供方的实际文本请求和官方账户余额读取。该结果不能扩称所有兼容接口、模型或账号均已验证。
- **其他来源按实际能力显示。** OpenRouter 已有官方密钥额度适配，但没有本轮真实账号成功证据。ZCode、DeepSeek Harness、豆包未接通公开账户额度接口时保持未知；桌宠对话的 token 消耗不代替外部工具剩余额度。
- **外部工具需要自己的环境。** Codex／ZCode 需安装支持对应事件的版本、审阅并信任本机命令、让新会话加载配置。DeepSeek Harness 需要原 Harness 安装及插件加载；本轮没有原宿主完整实跑证据。豆包当前接入普通方舟模型应用的 Function Calling 与本机桥，不自动监测豆包网页或 PC 客户端。配置已登记、本机桥已准备不表示原客户端已经连接。
- **AI 协同与分类的效果仍有条件。** 配置、取消、状态归属和数据边界已测；不同远程模型的真实协同质量与分类效果需要配置实际来源后验证，不能以固定本机响应代替效果验收。

## 原宿主独立运行的边界

原项目默认保留原逻辑，不强制改成本系统引擎。本系统不支持的动作、配置或 AI 操作灰色并说明原因。

- 官方 **Shimeji-ee 1.0.22＋Java 25** 已在隔离副本实际运行：原 JAR 创建单只宠物、读取原 XML、窗口响应并正常退出，运行前后原件字节一致。尚未验证所有姿势、脚本、桌面交互或 AI 功能。
- Windows EXE 和带有效入口的 JAR 可检测及明确选择；缺少运行环境时不可运行。启动使用独立参数数组，不执行上传清单里的任意命令，不自动安装依赖。
- VPet、AIRI 的已安装原应用可另行选择，但本轮没有实际安装运行验证；未核实作品载入参数时只启动原应用并提示手动导入，不称作品已经运行。
- Raycast、Live2D、VPet 原生逻辑，以及任意 JavaScript／Python 项目没有通用兼容执行器。仅有源码、XML、LPS、DLL 或图片不等于存在独立可执行程序。原生 SDK 插件默认依赖本系统，不具有独立运行入口。

详细范围见[原项目导入与独立运行](pets.md#检测兼容性保留原项目与显式素材转换)。
