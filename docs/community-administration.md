# 共创平台作品管理

入口为网站页脚的「管理员」，或 `/admin.html`。管理员用单独的管理密钥登录；普通访客无需登录。登录有效期八小时，点击「退出管理」清除当前浏览器会话。

登录后可按桌宠／插件、上架状态、分类筛选，也可搜索名称、作者及编号。分类栏既可选已有分类，也可直接填写新分类，点击「保存分类」。点击「下架作品」从广场、搜索、榜单、合集及作者页隐藏作品，本站下载接口和关联原素材地址也停止向普通访客提供。下架保留原件、署名及历史统计，点击「恢复上架」可重新公开。共享封面仅在关联作品都下架时停止公开。

修改保存在既有 Cloudflare D1 数据库，访客刷新后读取新状态，无需修改源码或重新部署。管理员仍可预览已下架的本站素材。已经下载到他人设备的文件、GitHub 等外站的原发行链接不在本站下架控制范围内。

当前管理对象为经本站 GitHub 投稿审核后编入公开目录的全部桌宠与插件。其他站点的投稿或仅在浏览器中的草稿不是已上架作品。

## 管理密钥与部署

维护者生成 32 字节随机密钥，以 64 位十六进制形式保存于自己的私有目录，并通过官方 Wrangler 的 `pages secret put ADMIN_KEY --project-name desktoppet` 从标准输入配置到 Cloudflare。禁止将密钥放入源码、浏览器本地存储、网址参数、提交记录或公开文件夹。重新配置该秘密并重新部署可轮换密钥，同时使旧签名会话失效。密钥丢失时可以生成新的密钥，无需公开原密钥。

`worker/catalog-management.mjs` 唯一持有作品覆盖状态、管理会话校验与登录限流。启用需要真实 D1 绑定和有效 `ADMIN_KEY`；首次访问通过幂等建表建立 `community_work_management` 和 `community_admin_login_limits`，不修改原素材或原目录记录。SQL 参数绑定、条件版本更新、来源检查和 HttpOnly／Secure／SameSite=Strict Cookie 保护管理写入；每个匿名来源每小时最多十二次登录尝试，数据库只存加盐摘要而不保存原始 IP。

Pages 全路径经过 Worker，使编码形式的静态链接不能绕过下架检查。媒体响应继续调用原登记名单及 Range 服务。数据库不可用时，受管理的素材和目录返回不可用，不退回未过滤的公开目录。本机只读预览没有管理后端，不能在该预览中保存公网更改。
